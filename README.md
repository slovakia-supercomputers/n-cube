# N-Cube

In-season nitrogen advice for cereal fields, built on open Earth-observation data cubes and IoT field measurements.

**Status:** planning. Source code, documentation and example inputs will be published here under the MIT licence as they are developed. Version 1.0 is the first complete release.

Maintained by [Slovakia Supercomputers s.r.o.](https://www.supercomputers.sk), Košice, Slovakia.
